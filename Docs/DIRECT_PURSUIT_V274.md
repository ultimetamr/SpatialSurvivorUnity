# 2.7.4 · 近身追击

按本轮要求：移除远程伤害、脚下常驻小圈；怪物直接追击玩家，扫描房间模型继续显示，冰冻技能仍可定身。

## 追击与伤害

- 删除敌方弹幕和伤害法阵池，普通怪、精英与三类首领的伤害全部通过 `TryEnemyContact` 校验，攻击间隔 0.8 秒。首领突刺在身体移动中命中，预警结束不会远程判定整条路径命中。
- 地面追击、冲锋蓄力、首领移动、击退和群体分离不再读取扫描网格的 Contains / Waypoint。飞行怪也不再被扫描墙体和家具 SphereCast 限制。所有生物仍使用同一米制世界坐标。
- 开始战斗后，局部扫描地面缺失不再暂停整场战斗；保留最后测得的地面高度，MR 服务、权限和真实跟踪仍需有效。首次进入战斗仍需房间就绪。
- 出生点围绕当前玩家生成，保留最小出生距离及同类身体间距，缺失扫描地面不会阻止出生。晶核防守模式继续追击晶核，不改变模式目标。
- 以当前目标为直接方向，仅近身时小幅侧移防止生物叠在同一点。群体优先寻找可用方向，全部被堵时沿最近目标方向继续前进；保持速度限制，不瞬移。
- 保留护盾、治疗、冲锋、精英词缀、首领阶段、死亡动画以及玩家武器/魔法。怪物图鉴和首领介绍与近身攻击逻辑同步。

## 圆圈与房间

隐藏 `Attack Range` 常驻线圈和金色 `MagneticField` 可视圈，不改变真实攻击范围或金币/经验吸附效果；有伤害的玩家毒雾、雷域继续显示。首领仅保留实际冲锋路径提示，其余无伤害地面预警隐藏。

扫描后的主题地板、墙面和家具模型、主题开关与原始测量数据保留。虚拟怪物穿越这些数据，不修改系统 Guardian 或跟踪规则。冰冻、主动暂停、升级选卡和失去定位时的保护继续生效。

## 验证

执行完整 Unity 回归，包括所有普通物种/首领的远处不扣血及近身伤害、缺失地面与扫描墙体穿越、拥堵后直接靠近、冰冻与暂停、常驻圈隐藏且攻击范围和房间主题保留。

构建记录、APK 校验和设备验收范围见 [验证摘要](Validation/v274-direct-summary.json)。编辑器测试与本机构建不能代替头显实际追击、舒适度及 PICO 云端审核。
