# 真实挥击与枪械 · 2.2.0 / code 12

## 使用

主菜单 → 武器商店 → 第二页，免费领取「星火手枪」并装备；「符文霰弹枪」售价 240 金币。装备后下一局生效。符文短剑保留原 80 金币价格。旧存档、六把原武器的编号、已购状态和装备保留。

- 符文短剑：不按扳机也可挥动手柄击打。挥击检测手柄移动和剑尖旋转轨迹，使用帧间扫过的整段剑刃；单次横扫可击中多个生物。同一生物基础重复命中间隔 0.32 秒，受局内攻速影响，避免每帧重复扣血。静止持剑不自动造成接触伤害；也可按住扳机按原 0.48 秒基础间隔斩击。
- 星火手枪：免费领取；32 基础伤害、0.28 秒基础间隔、12 米距离、28 m/s 子弹。按住扳机连续射击，带枪口闪光、弹道和模型后坐。
- 符文霰弹枪：240 金币；每次五枚子弹，每枚 14 基础伤害、0.80 秒基础间隔、8 米距离、20 m/s 子弹。近距离可多弹命中同一目标，基础全中伤害为 70。
- 剑和枪均可攻击地面怪与飞行怪；伤害和攻速随本局强化成长。击杀加入原有经验、击杀数与局外金币结算。

## 跟踪修正

原来每次读取严格 isTracked，有一个失效采样就隐藏武器，并立即切到另一只可用手柄；只保存射线方向也会丢失手腕旋转。

现在模型跟随完整手部旋转。原手柄短时失效时保留最后有效姿态最多 0.22 秒，防止挥动时一帧闪烁或瞬间跳到另一只手。保留显示期间禁止使用旧姿态攻击；持续丢失超过该时长才隐藏。恢复、输入源切换、暂停返回后需要松开扳机再攻击，丢失前后不连接挥击轨迹。明显位置跳变也不计作挥击。

此修正处理应用层短时断帧，不能恢复硬件长时间离开跟踪范围后的真实手部位置。实际大幅挥动是否仍有长时间失跟，需要佩戴真机确认。

## 碰撞与展示

剑刃扫掠共享最多 97 组房间检测，避免每个怪物重复进行全部扫描网格查询；命中使用各目标独立间隔和对象池代次。扫描墙壁/家具可阻挡近战和子弹；枪口前被阻挡时不能从墙后生成子弹。子弹按剩余距离裁剪最后一帧，避免高速子弹跳过目标或超出射程。

延续此前关闭真实房间深度遮挡的渲染方式。商店中的战斗怪物暂时隐藏，返回战斗后恢复；枪械预览采用斜侧角度以显示轮廓。
