# 2.7.1 · 自由追击

此为历史版本记录。房间主题替换应保留，移除主题的改动已在 [2.7.2 房间漫游](ROOM_MR_V272.md) 纠正；当前以 2.7.2 为准。

用户澄清：实际问题是走动后怪物停在一定范围内、不再追击，以及扫描后生成的网格模型需要移除。本轮围绕怪物导航和透视画面修复，保留真实走位、怪物避让、武器战斗与旧存档。

## 追击修复

- 完整扫描地面与实时网格同时参与导航。此前只要实时网格有数据就停用完整扫描表面，即使实时网格只有一小块地面且仍满足“就绪”条件，也会把怪物限制在局部区域。
- 玩家走动后刷新导航缓存，导航窗口随玩家移动；扫描范围中保留已有怪物所在的通行分区，刷怪仍使用玩家所在的连通分区。
- 栅格基础检测不再统一使用 0.22 米半径。先记录可用地面，再按各怪物自身的实际半径判断通行，避免小型怪被窄通道错误挡住。
- 目标点落在家具、扫描边缘等不可达位置时，在可达地面内寻找最接近目标的位置，避免整次寻路直接返回怪物原地。
- 飞行怪增加绕墙路径，避免只依赖局部转向反复停在墙前。地面与飞行怪仍保留相互避让、真实障碍检测，以及冻结、施法和暂停行为。

没有添加穿墙、瞬移追击或虚构未扫描地面的逻辑。玩家进入实际不可达区域、扫描缺少地面或真实墙面隔断时，怪物仍受测量数据约束；本修复不承诺无限空间或跨楼层追击。

## 去除房间模型

- 运行时不再创建扫描房间的主题替换模型；已有设备保存的“魔法场景开启”偏好不再启用模型。
- 扫描网格仅保留不可见碰撞数据，移除游戏内“空间网格预览”和“魔法场景”按钮。
- 编辑器模拟地面、墙壁与家具同样隐藏渲染，保留碰撞和导航；独立美术生成与历史主题预览代码仍保留供开发参考。
- MR 设置明确说明：扫描数据仅用于地面与追击导航。游戏保持透视画面、怪物、武器和 UI。

## MR 策略与构建

另外发现 `Assets/Resources/PXR_ProjectSetting.asset` 原为 `mrSafeguard: 0`，2.7.0 的 Android 工程同样声明 `enable_mr_safeguard=0`。启用 PICO SDK 6.1.1 的 MR Safeguard；其自带 `PXR_ManagerEditor.cs` 说明开启后采用 MR 安全策略，关闭时默认采用 VR 安全策略，`PXR_BuildProcessor.cs` 将该设置输出为应用 metadata。

初始化、Android 生成后处理和云快照导出均要求 `enable_mr_safeguard=1` 与 `enable_vst=1`；错误或重复声明会终止构建/导出。不关闭系统 Guardian，不隐藏系统障碍提示；失去定位或系统暂停时仍停止战斗。实际系统策略由设备执行。

版本升级为 2.7.1 / 22。应用名称、包名、图标和存档保持兼容。
