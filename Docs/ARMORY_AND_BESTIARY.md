# 技能手册、飞行生物与手持军械 · 2.1.0 / code 11

参考项目：`D:\Would\DOME\my-pico-unity-app` 的 RoomSiege。参考其图鉴的实际模型、属性说明、翻页，以及军械商店的购买/拥有/装备状态；没有修改 RoomSiege，也没有引入其塔防运行逻辑。

## 操作入口

- 主菜单右侧新增「技能手册」「生物图鉴」「武器商店」。暂停页也可进入；关闭后回到暂停页，再继续战斗。结算页可直接进入商店。
- 技能手册收录现有 39 张技能卡，显示技能效果、稀有度、等级上限与六种传说进化的完整条件。技能继续通过局内升级获得。
- 生物图鉴收录 7 种怪物，显示实际动画模型、基础生命/伤害/速度、出现波次、行为和应对方法。普通怪的后续波次数值仍会成长。
- 商店展示六把实际武器模型，可查看价格、攻击数值、距离和特殊效果。没有拥有的武器可永久购买，已拥有的武器可免费装备。金币不足时不能购买；购买时保存失败会回滚金币和拥有状态。
- 进入战斗时锁定本局手持武器。暂停时购买或换装将在下一局生效，避免一局内绕过冷却切换武器。
- 优先绑定右手柄，右侧不可用时使用左侧；手势模式支持有效手部瞄准与捏合。编辑器使用左键和镜头朝向。短剑支持扳机斩击或快速移动手柄挥击，其他武器可按住连续发射。
- 从菜单进入战斗、恢复跟踪或关闭弹窗后，需要先松开扳机/捏合再攻击，防止菜单点击带出一次攻击。暂停、选卡、定位丢失及命中停顿时，手持攻击与弹体使用同一战斗时钟。

4. 焰种法杖：200 金币；30 基础伤害，0.85 秒间隔，7 米距离；命中后 0.75 米范围伤害并附加灼烧。
5. 雷羽魔杖：280 金币；19 基础伤害，0.30 秒间隔，8 米距离；向 1.2 米内最多 2 个其他目标连锁，连锁伤害为 70%。

伤害随本局伤害倍率成长，攻击间隔受本局攻速影响；武器有真实冷却、固定 24 个手持弹体池、命中去重与对象池代次检查。手持弹体及近战会被扫描墙壁/家具阻挡。自动能量弹已改为按目标实际高度瞄准和三维线段命中，能够打到飞行怪。

## 飞行生物

- 星粉飞蛾：第二波起出现，35 基础生命、7 伤害、0.85 m/s。
- 雷翼幼龙：第三波起出现，85 基础生命、13 伤害、1.05 m/s。

- 使用真实空中位置追击，在玩家胸口附近环绕，具有高度浮动。三维身体间距、扫描表面球体碰撞与分步移动防止飞行穿墙和重叠；保留冻结及暂停。飞行高度约地面上 0.75～1.8 米，依玩家高度调整。
- 在原 18 个普通怪池和 1 个 Boss 之外预热 6 个飞行怪槽；同时存活普通怪上限仍为 18，飞行槽参与同一上限。Boss 登场清理所有普通地面/飞行怪。
- 空中死亡掉落的经验落到导航地面高度，继续使用原吸附流程。

## 局外金币

金币与原有永久强化晶核分开保存。每次正常胜利、失败，或从暂停返回主菜单时结算：每击杀 3 金币，每完整生存 10 秒 2 金币，每完整生存 120 秒另加 20 金币，通关另加 120 金币。零时间零击杀退出奖励为零。重复进入结算/主菜单不会重复发奖。

旧版存档升级至 v3，保留晶核、永久强化、声音和触觉设置，默认免费拥有并装备星光魔杖，金币初始为零。损坏主存档恢复、临时文件/备份恢复流程继续保留。
