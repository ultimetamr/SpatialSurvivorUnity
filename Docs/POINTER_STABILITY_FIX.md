# 射线与扳机稳定性 · 2.0.4 / code 10

用户反馈手柄射线不稳定，UI 要点几次才响应。旧版只记录成功点击，无法从已有真机日志判断每次失败是跟踪、输入切换还是按钮边缘偏移。已读到的真机记录确认成功输入来自 RightController。

## 可复现的问题

旧射线直接使用每帧姿态，无任何平滑；按钮只按扳机按下当帧的严格矩形命中决定是否点击，未命中会消耗本次按下。实际菜单回归复现：先瞄准 MR 设置按钮边缘，按下时向外偏移约 6 毫米，旧实现仍停留在 Menu，未进入 MR。修复前结果为预期失败，见 Validation/pointer-before.xml。

扳机使用数字按钮与模拟轴 >= 0.65 的组合，没有独立松开阈值。模拟值在边界上下波动时可能反复改变按下状态。

## 修复

- 非鼠标射线统一做与帧率无关的姿态平滑，小抖动被抑制，大幅主动转向快速跟随。命中、线条和光点共用同一条过滤后射线。换手、跟踪失效或长帧后重置，不跨设备插值。
- 同一个输入源已经悬停的按钮增加 12 个 Canvas 单位（约 12 毫米）的有限保留范围。优先选择精确命中的新按钮。不会吸附远处目标，不会借用另一只手的悬停，也不会触发已禁用/隐藏的按钮。
- 支持模拟轴时，按下阈值 0.55、松开阈值 0.25，避免扳机在单一边界附近反复跳变；不支持模拟轴时仍使用数字按钮。左右手柄分别维护状态。
- 按住扳机只触发一次，换页和跟踪恢复后仍须松开再按，避免点击穿透。
- 调试记录新增 missedPresses、sourceSwitches、trackingLosses 与 trigger 模拟值/数字状态；每次有效按下立即落盘，未命中时也写日志，不再只记录成功点击。

完整回归结果：Validation/pointer-stability-tests.xml。版本、APK 校验与实际部署状态：Validation/pointer-stability-summary.json。上述复现说明代码中的漏点路径；真机抖动观感和具体失败输入仍应结合新版诊断与佩戴反馈确认。
