# 怪物重叠修正 · 2.0.2 / code 8

用户反馈怪物追到一起后互相叠加。原移动只检测真实房间，没有角色之间的空间占用；所有怪物也都以玩家中心为终点。出生点没有预留空位，落地和黑洞位移可能进一步造成重叠。

修正内容：

- 根据新模型的身体、手臂及翅膀设置独立避让圆盘半径：0.27 / 0.29 / 0.46 / 0.40 / 1.05 米。战斗伤害与房间碰撞的原半径保持不变。
- 靠近其他怪物时选择侧向移动方向，移动过程以最多 6 厘米的步长检查，防止高速怪物穿过同伴。
- 靠近玩家时停在近战攻击距离，不再持续往玩家中心挤；外围怪物等待或绕行寻找空间。
- 每个战斗步结束后处理落地、黑洞拉拽及已有重叠，按限定速度分开；分离仍必须满足房间地面、墙壁与家具碰撞。
- 冻结怪物及 Boss 蓄力保持原位，其他怪物绕开；死亡动画占用位置直到结束。暂停时不推进分离。
- 刷怪检查现有怪物、死亡身体与空降怪物的预定落点；占用后继续寻找其他出生点，无空位时延后刷怪。Boss 登场会清理普通怪，保持原流程。

72 项完整游戏测试通过，含 9 项新增：18 只同时追击、实际战斗混合波次及空降落地、完全重合恢复、冻结、高速防穿越、出生点与死亡占用、拥挤出生点选择、贴墙分离和暂停。实际战斗测试禁用伤害并推进 540 步，检查所有 18 只仍存活、正常落地、保持互相间距且留在有效房间范围。

结果：`Docs/Validation/crowd-tests.xml`。安装版本、APK 校验值及启动状态见 `Docs/Validation/crowd-summary.json`。真机观感仍需佩戴确认。
