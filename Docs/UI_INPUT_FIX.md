# UI 点击修复（2026-11-05）

Unity 版本 1.3.1（code 5），保留包名和用户进度。

旧代码先返回任何有效手势射线，可能遮蔽实际手柄；同类输入只返回第一个右侧设备，左侧确认无法接管。修复后优先响应实际按下扳机的手柄，按 PICO 当前输入模式选择手势/手柄，支持左右切换及扳机模拟轴。手势同时接受 SDK 的 AimRayTouched 和 AimIndexPinching。

浮动 UI 命中不再被扫描网格中的噪声三角形拦截；加入命中光点、按下颜色和当前输入/按钮提示。菜单重建、持续按住扳机、跟踪恢复仍要求松开，避免一次点击穿透到下一页面。开发包在 persistentDataPath/ui-input.txt 每两秒保存输入状态和点击计数，便于真机诊断。

51 项测试通过：新增 6 项覆盖左右确认优先级、丢失输入回退、持续按住与模态切换、真实菜单监听器命中、网格噪声和禁用按钮。完整结果：Validation/ui-input-tests.xml。原场景回归的死亡动画检查补齐选卡处理，避免升级弹窗暂停后误判动画未完成。

本版已覆盖安装到 PICO B3110。安装、启动和人工点击验收状态记录在 Validation/ui-input-fix-summary.json；自动化测试不能替代佩戴实测。
