# 无遮挡与持续移动修正 · 2.0.3 / code 9

用户要求：UI 和怪物不被房间遮挡，怪物整体缩小两倍；防止怪物相撞时仍应持续移动。

- 真实扫描网格默认禁用 MeshRenderer，MeshCollider 继续供导航与房间碰撞使用。网格预览按当前开关同步到现有及新增扫描块。
- 房间材质关闭深度写入；隐藏预览时丢弃片元。即使误启用渲染器或开启诊断预览，也不会在虚拟角色和 UI 前写入遮挡深度。
- 五种怪物（包含 Boss）缩放为此前的 50%，房间碰撞/战斗半径和身体避让半径同步减半。移动速度、动画与攻击逻辑保留。
- 移除近战距离的强制停步，靠近玩家后沿攻击距离持续绕行。被同伴挡住时搜索侧向和后向通路，再继续追击；保留出生空位检查及战斗步后的身体分离。
- 冻结、暂停、Boss 蓄力仍按原规则执行；房间导航继续避免穿过墙壁和家具。

73 项游戏回归全部通过：包含实际渲染到 RenderTexture 的房间前景 / 模型 / 世界 UI 测试；18 只怪物围攻的持续行程和身体间距；堵路同伴绕行；混合实际战斗波次落地后推进 1080 步，所有普通怪保持活动、持续移动，玩家确实受到近战伤害；五种尺寸及半径、冻结与暂停也已验证。

测试结果：Validation/visibility-movement-tests.xml。APK 校验值及实际设备启动状态：Validation/visibility-movement-summary.json。编辑器模拟房间回归不能代替佩戴头显的视觉确认。
