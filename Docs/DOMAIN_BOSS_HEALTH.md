# 2.3.0 领域、首领与血量显示

工程：E:\DEMO\SpatialSurvivorUnity。Unity 6000.6.8f1；PICO Unity SDK 6.1.1；包名 com.example.spatialsurvivor.unity。

## 实现

领域每种使用一个动态网格渲染器，30 Hz 更新符文与粒子，战斗暂停、失跟门控和受击停顿时同步冻结。毒域半径为攻击范围 × 1.35，幽冥毒域再乘 2，雷域为攻击范围 × 1.55，磁吸领域为拾取范围 × 2。毒域持续伤害与雷域麻痹概率保持原规则；雷击脉冲向实际命中的目标连接电弧。

首领于 120 / 300 / 600 秒登场，复用已有古树生物骨骼资产，配有三种色调和悬浮晶冠。每位首领均有三个血量阶段（65% 与 30%），循环追击、冲击和荆棘攻击。预警在蓄力开始时锁定位置与半径，期间玩家可以移动躲避。出生点优先距离玩家 3 米；小房间自动回退至至少 1.2 米，仍检查 Boss 体积与墙体间距。若无可用位置继续尝试，不锁死普通刷怪。Boss 存活时暂停普通刷怪；击败后恢复正常波次，最终首领死亡才胜利。

每个敌人对象池预建血条，不在受击时实例化 UI。文字显示精确当前值；绿色/红色填充跟随生命比例，金色残血条缓降。使用源网格顶点包围盒计算头顶锚点，避免复用出生/死亡动画的旧包围盒。血条朝向观察相机并按距离缩放，不参与射线交互。保留房间不遮挡 UI/怪物的既有规则。
