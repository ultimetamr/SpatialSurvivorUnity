# 战斗 HUD 位置修正 · 2.0.1 / code 7

用户反馈持续跟随的血条/技能栏位置和角度不舒服。

原实现将头部当前 forward 向下旋转 15 度作为 HUD 位置，面板却只匹配水平朝向。结果是用户低头查看 HUD 时，HUD 又继续下移，同时面板缺少面向眼睛的倾角。水平转头时面板朝向立即变化，位置却插值移动，也会产生不一致。

修正后：

- HUD 在水平前方 1.6 米、眼睛高度下方 0.48 米，中心约低于水平视线 16.7 度；保持原尺寸 0.84 × 0.22 米。
- 位置依据水平朝向，低头、仰头和头部侧倾不会把 HUD 推走。
- 面板法线从眼睛指向面板中心，保持文字水平并面向双眼。
- 小幅查看维持世界朝向；转头超过 24 度并持续 0.3 秒后，以每秒 55 度跟随转身，避免一直追随视线。位置平滑跟随身体位移，追踪大幅跳变直接重新放置。
- 在 LateUpdate 设置 HUD 姿态后再计算射线点击，菜单、暂停、升级期间隐藏 HUD，重返战斗时重置位置。
- 按用户后续明确的范围，仅修改战斗 HUD；主菜单和升级面板保持原定位。

五项姿态测试覆盖下方距离/正对眼睛、低头及侧倾、短暂查看及持续转身、追踪跳变、接近竖直视线。完整游戏与输入回归结果位于 `Validation/ui-placement-tests.xml`。头显佩戴舒适度仍以用户实际体验为准。
