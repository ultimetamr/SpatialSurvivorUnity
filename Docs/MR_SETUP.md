# MR 接入与验收

本次补齐 Unity 版的 MR 运行流程。项目路径：E:\DEMO\SpatialSurvivorUnity；使用嵌入的 PICO Unity SDK 6.1.1。应用版本 1.3.0（code 4）。

## 使用

在支持该 SDK 的 PICO 头显安装 Builds/SpatialSurvivorUnity.apk，启动后允许空间数据访问。

主菜单 →「MR 设置 · 扫描房间 / 网格预览」：

1. 查看透视、定位、坐标原点、实时网格、场景表面数、通行面积和错误信息。
2. 点击「扫描 / 重扫房间」进入系统房间扫描，标记地面、墙壁、天花板和家具后返回应用。
3. 开启「空间网格预览」核对扫描表面与真实房间的位置，关闭后只保留导航和碰撞，不渲染遮挡。
4. 空间授权被拒绝或服务启动失败时，点击「重新授权 / 重试 MR 服务」。永久拒绝权限需要先在系统应用权限页开启。
5. 回到主菜单，定位稳定且有效地面网格就绪后才能开始。游戏中可从暂停菜单重新进入 MR 设置。

Unity 编辑器使用明确标注的模拟房间；系统扫描、透视、重新授权和真实网格预览不在编辑器中伪造。编辑器中的「刷新模拟房间」仅重建模拟导航。

## 实现

- **场景与配置**：XR Origin、透明背景双眼 Main Camera、SurvivorPlatform 和 SurvivorMrSession 保存于场景；PICO Loader、自动 XR 初始化、手部追踪、空间网格、sceneCapture 和 videoSeeThrough 配置在初始化/构建流程中写入。
- **启动与恢复**：等待 PICO Loader、请求并确认空间权限与可选手部追踪权限、启动 XRMeshSubsystem 和 SceneCapture sense provider；手势权限拒绝时保留手柄输入；显示超时/拒绝/错误并允许重试。已启动的场景服务会复用。
- **透视**：通过 PXR_Manager.EnableVideoSeeThrough 开启系统 VST，保留相机透明背景，恢复应用时重新应用。
- **跟踪**：优先使用 Floor tracking origin；相机更新真实 HMD 位姿，在 before-render 再次采样。0.35 秒内没有有效位姿暂停，连续有效采样 0.15 秒后恢复；不添加虚拟摇杆。
- **房间数据**：订阅实时空间网格增删改；首次收到 Unchanged 但本地不存在的网格也会加载。独立管理 Unity Mesh、MeshCollider 和诊断预览材质，销毁时释放。
- **扫描房间**：调用 StartSceneCaptureAsync，完成后 QuerySceneAnchorAsync；读取真实场景多边形、二维边界及三维家具包围盒。凹多边形使用耳切三角剖分，双面碰撞保留凹边界。完整查询会清理已删除的房间表面。
- **导航与家具**：扫描表面进入专用碰撞层。实时网格地面就绪后优先使用实时表面；实时扫描暂时只有墙壁时，保留已捕获房间作为地面后备。导航继续限制出生、追击路径和天花板掉落。
- **遮挡与预览**：2.0.3 起禁用真实房间的深度遮挡；默认关闭网格渲染，透视 alpha 不受影响。预览时显示青色扫描表面，但不写入深度，不遮挡怪物或 UI。
- **输入反馈**：手势瞄准射线和捏合优先，手柄射线与扳机备用；增加实际关节位姿驱动的双手指骨轮廓。真实手势可用性仍需头显验证。
- **游戏门控**：授权、初始化、扫描、读取房间、定位丢失、房间无有效地面时禁止推进战斗；MR 设置页面本身也暂停游戏。

代码入口位于 Assets/Scripts/Platform，MR 菜单位于 Assets/Scripts/UI/SurvivorUI.cs。选中场景根对象的 SurvivorMrSession，可在 Inspector 查看中文说明；Play 后可查看状态并触发对应操作。

## 验证边界

编辑器测试可证明状态门控、扫描网格数据的增删改/碰撞/导航、凹地面边界、无房间深度遮挡的着色器及菜单接线工作。编辑器模拟不能证明系统 VST、原生扫描界面、设备空间数据、双眼定位、手势权限或真机性能已通过。

本轮 pico-cli 设备列表为空，未安装/启动 APK 到设备。环境检查显示公共 CLI 可用；其全局 AI 工具配置仍针对 Spatial/Kotlin，未改动该全局配置。游戏实际使用的嵌入 Unity SDK 与 Android 构建不依赖该全局 AI 工具配置。

真机验收顺序：首次授权与拒绝重试 → 真实透视 → 系统扫描/取消/重扫 → 地面与家具对齐 → 网格预览 → UI 和怪物不被真实家具遮挡 → 手势捏合与手柄备用 → 离开/恢复定位 → 暂停中重扫 → 连续十分钟运行。
