# 2.5.0 · 战斗与试炼

本轮按高完成度体验目标完善实际玩法，不将功能数量或自动化通过数等同于用户五星评分。

## 已实现

- 近战连续轨迹判定保留；剑尖速度达到 2.8 m/s 时为 1.6 倍重击。增加有限击退、短受击停顿、闪光、伤害数字和触觉。移除普通自动攻击造成的全局停顿，敌群持续移动。枪械/法杖音效各自区分。
- 三种首领模型与六段动画：荆棘守卫交替震地和锁定突刺，月冠女王交替地面标记和月环，古树守望者轮换圆震、荆棘和五发扇形弹。突刺横向躲避，月环内圈与外圈安全，攻击预警与真实判定匹配。图鉴可切换三位首领。
- 经典生存首个 45 秒馈赠，之后每 150 秒到达节点可选伤害/恢复/带风险金币；首领在场时跳过该次馈赠。精英狩猎 18 秒内连续击杀可获得连击金币。晶核守卫以击杀积累能量，20 能量恢复 60 生命，15 能量放置 8 秒冰阱，最多三处。无尽每次击败首领后选择契约，提升敌我属性与结算收益。
- 精英追加晶盾/狂奔/孵化词条；孵化产生普通小怪，并受当前房间怪物上限约束。
- 四个累计挑战：50 击杀、8 精英、3 首领、四模式目标，金币奖励分别 60/100/160/240。前三项解锁破阵/速射/霜痕核心。核心下一局生效，领取失败会恢复金币和领取标记。
- 行者指南、舒适度页面与挑战页面。HUD 距离 1.2–2.2 米、低于视线 0.25–0.8 米、比例 75–120%，可选转头缓跟或固定朝向；精简 HUD 默认开启，简化特效保留攻击预警与怪物血量。
- 房间面积参与怪物上限（8–18）与敌方地面法术尺寸（65–100%）限制；飞行绕行增加垂直候选方向与拥挤脱离。
